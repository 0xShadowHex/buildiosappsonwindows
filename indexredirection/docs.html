Getting Started

  1. Open iCodeWin editor by clicking "Start Building"
  2. Create a new project and name it in the prompt
  3. Code your Application in HTML, CSS and Javascript X Swift while enjoying our live preview
  4. Once you are done, click "Download .ipa" to get your unsigned .ipa file
  5. Sideload your .ipa file using the tools listed in sideload section of Docs

Link notification API to project

Link notification API as first link in body for it to work. It is pre-linked by default.
Code snippet:
<script src="../js/notification.js"></script>

Common errors:

Common errors are:
Unstable Internet: Fixed by connecting to a stable Wi-Fi.
Failed to fetch: Fixed by waiting for us to get our servers back online (usually done within 48h)

Sideloading tools

  1. Our partner, Scarlet
  2. Tool to sideload from PC, iLoader
  3. Use PC once, refresh with VPN: SideStore
  4. Use PC once, refresh over home Wi-Fi: Sideloadly
  5. Refresh by connecting PC and Phone with a cable every 7 days: AltStore
